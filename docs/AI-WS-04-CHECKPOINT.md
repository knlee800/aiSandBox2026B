## Implementation Summary

- Added lightweight optional metadata fields to `workspaceContext`:
  - `projectName?: string`
  - `workspaceName?: string`

### `frontend/app/[locale]/app/page.tsx`

- Extended `WorkspacePromptContext`.
- Derived `projectName` from the currently selected project in `workspaceProjects`.
- Derived `workspaceName` from the currently selected workspace in `workspaces`.
- Trimmed names and omitted blank values.
- Passed both names through the existing `buildWorkspacePromptContext(...)` path at both AI execute call sites.
- Preserved existing file path list, selected file path, and selected file content behavior.

### api-gateway

- Extended `WorkspaceContext` with `projectName` and `workspaceName`.
- Existing controller forwarding remained unchanged because it already forwards `workspaceContext` opaquely.

### ai-service

- Extended queue `WorkspaceContext` with `projectName` and `workspaceName`.
- Updated `buildWorkspaceContextBlock(...)` to prepend concise metadata sections when present:
  - `Current project:`
  - `Current workspace:`
- Preserved no-context / no-metadata behavior when absent.

### Tests

- Focused forwarding and worker tests were updated to include the new metadata fields.
