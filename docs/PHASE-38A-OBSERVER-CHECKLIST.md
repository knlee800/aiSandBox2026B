# PHASE-38A — Observer Checklist (Quick Reference)

---

## Pre-Test Setup

### System Verification
- [ ] Platform is running at `/[locale]/app`
- [ ] All services operational (API Gateway, AI Service, Container Manager)
- [ ] Monitoring/logging enabled
- [ ] Test environment documented

### Observer Preparation
- [ ] Screen recording software ready (or detailed note-taking setup)
- [ ] Timer available for measuring task duration
- [ ] Observation framework reviewed
- [ ] Issue recording template ready
- [ ] No hints/guidance mindset confirmed

### User Preparation
- [ ] 2–5 external developers recruited
- [ ] No prior platform exposure confirmed
- [ ] No pre-briefing provided
- [ ] Users understand they'll be observed
- [ ] Users consent to recording (if applicable)

## Reminder: Observer Rules

**DO:**
- ✓ Observe quietly
- ✓ Record everything
- ✓ Time all tasks
- ✓ Note emotional tone
- ✓ Capture direct quotes

**DO NOT:**
- ✗ Give hints (unless completely blocked)
- ✗ Explain system behavior
- ✗ Lead with questions
- ✗ Fix issues mid-test
- ✗ Suggest solutions

---

## Next Steps After Testing

2. Classify all issues by priority
3. Complete metrics tables
4. Write readiness assessment
5. Declare: SHIP / ITERATE / BLOCKED
6. Stop — do not implement fixes
