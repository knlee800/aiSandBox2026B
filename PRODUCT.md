# Product

## Register

product

## Users

Authenticated people building software with AI inside isolated project workspaces. The current shell is the ainow.biz command center; Builder is the functional agent. A later limited private beta, deferred on 2026-10-31, is a small trusted cohort (1–3 people) on email and password sign-in. Admin user, session, and credit tools are operational support, not a public product surface.

## Product Purpose

ainow.biz is the umbrella. Builder lets a user Ask (a reply, no file changes) or Build (workspace file changes, credits only after a qualifying apply) on a durable project: files, chat, preview, and git checkpoints survive the session. User-created agents can be saved and bound into that same workspace for bounded Ask and Build. Other named agents are coming-soon placeholders. Success is a project the user can resume, reverse, and read in English, Traditional Chinese, or Simplified Chinese.

## Brand Personality

Three words: safety, reversibility, clarity. Voice is plain and specific. The product should feel like Linear in its calm, dense interface and like Cursor in its workspace layout (project, chat, files and preview side by side). The RPG-inspired command-center look belongs to the platform shell and the office page only; the Builder workspace stays calm and plain.

## Anti-references

- Generic AI-product marketing: purple gradients, neon accents, glassmorphism
- A new visual theme that ignores the screens already shipping
- Decorative motion that ignores prefers-reduced-motion
- Layouts sized only for English

## Design Principles

1. The screen is a workspace for a project, chat, files, and preview.
2. Failure, credit use, and reversal stay visible.
3. Every user-facing string exists in English, Traditional Chinese, and Simplified Chinese.
4. Risky or batch file changes wait for confirmation.
5. Unfinished agents stay visibly coming soon, not functional.

## Accessibility & Inclusion

CURRENT and limited private-beta copy must exist in `en`, `zh-TW`, and `zh-CN`. The target is WCAG 2.2 AA. `prefers-reduced-motion` applies to the whole product, not only the office page.
